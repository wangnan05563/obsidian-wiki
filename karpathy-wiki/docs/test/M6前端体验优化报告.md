## Design Decisions

| Decision | Rationale |
|----------|-----------|
| Ingest submitting lock | 100ms delay + store.isCompiling cross-component guard |
| QQ indeterminate | Backend doesn't return % during upload/extract |
| Health component ref | UI-only, no cross-view persistence needed |
| Config watch deep | Multiple fields, manual tracking error-prone |
| JSON.stringify snapshot | Most reliable deep comparison |
