## 4. 技术调研：路由改造方案（N4 / T02394 前置结论）

**现状证据**：
- `frontend/src/App.vue:53` `menuItems` 15 项；`const currentView = ref<ViewName>('dashboard')`；`go()` 权限守卫（`App.vue:108-111` 附近，校验失败仅 `console.warn`）。
- 全项目 **无 vue-router**（6 处注释显式声明不引入：App.vue / useIsMobile.ts / Query.vue / MobileBrowse.vue / MobileShell.vue / RefsList.vue）。
- 跨视图跳转已有 CustomEvent + sessionStorage 机制（Query.vue）；移动端 MobileShell 独立 tab 切换。

**方案对比**：

| 方案 | 成本 | 收益 | 风险 |
|---|---|---|---|
| A. hash 同步 currentView（`#/query`） | 中（1 个 composable + go/App 接线） | 刷新保持/回退/深链全解决 | 低：不动渲染架构，与「不引入 vue-router」约定一致 |
| B. 引入 vue-router | 高（15 视图改路由表 + 守卫迁移 + 移动端分支） | 同上 + 嵌套路由未来能力 | 中：违背项目既有约定，回归面大 |
| C. 不改 | 0 | 无 | N4 保持 P0 |

**结论：选 A（hash 同步）**。落点：`composables/useHashView.ts`（hashchange 监听 + `go()` 内同步 hash + 非法 hash 回落 dashboard + 移动端 hash 不联动或只读映射），T02394 实施。
