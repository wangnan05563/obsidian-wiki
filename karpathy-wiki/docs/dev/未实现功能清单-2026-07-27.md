## 8. 须坚守的核心约束（V3.1 §6）

V3.1 演进实施过程中须始终坚守以下 8 项约束：

1. 不退化 compile 为查询时 RAG
2. 不放弃结构化页面输出（vault 四类页面模板）
3. 不放弃双向链接图谱（不能用 GraphRAG 隐式图替代显式 `[[链接]]`）
4. 不放弃 Harness 抽象（Agent = LLM + Harness）
5. 不放弃 health-check-fix workflow
6. **禁止引入独立 NER 模型或向量库**（实体抽取由 LLM 在 compile 阶段完成）
7. **禁止跨源 RAG**（外部源 Connector 仅用于将外部内容抓取到 `raw/`，须走 compile 入库）
8. **禁止依赖 Obsidian 专属插件作为核心功能**（核心功能须在 Web 前端零安装环境下可用）
