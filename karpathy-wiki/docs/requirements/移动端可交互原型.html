Software 2.0 是什么意思？
🤖
💭 正在检索知识库与联网资料…
Software 2.0 是 Karpathy 提出的概念：传统「Software 1.0」由人写显式代码；而 Software 2.0 中，程序员只定义目标与数据结构，权重（参数）由优化器在数据中自动学习得到。典型例子是神经网络替代手写逻辑。
