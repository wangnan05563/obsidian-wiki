# 注册用户与认证用户对比

[[票据综合服务平台]] 按照身份验证强度将用户分为**注册用户**和**认证用户**两类。

## 对比表

| 对比维度 | 注册用户 | 认证用户 |
|---------|---------|---------|
| **身份验证** | 仅绑定手机号 | 已完成实名验证流程 |
| **功能权限** | 浏览主页、查看资讯、查询贴现行情、查询票据承兑信息披露和承兑人信用信息披露 | 包含注册用户全部功能 + 票据账户查询、信息披露、贴现询价、交易信息查询等 |
| **角色管理** | 无 | 可设置管理员、操作员等角色 |
| **注册步骤** | 录入手机号 → 填写验证码 | 绑定手机号成为注册用户 → 设置管理员信息 → 填写企业基本信息 → 小额签票验证 → 法定代表人授权 → 确认平台服务协议 |
| **业务办理** | 不可办理业务 | 可代表企业/金融机构办理业务 |

## 详细说明

### 注册用户
通过互联网渠道进入 [[票据综合服务平台]]，已绑定手机号但尚未完成实名验证流程的用户。

**可使用的功能：**
- 浏览平台主页面
- 查看平台资讯信息
- 查询贴现行情
- 查询票据承兑信息披露和承兑人信用信息披露

### 认证用户
已完成实名验证流程的用户，可使用 [[票据综合服务平台]] 的全部功能。

**额外功能：**
- 票据账户查询
- 信息披露
- 贴现询价（参见 [[票据贴现服务]]）
- 交易信息查询
- 设置管理员、操作员等角色

## 用户类型（按身份）

除按认证强度分类外，综服平台用户还按身份类型分为：

| 类型 | 说明 |
|------|------|
| **企业** | 金融机构以外的法人、非法人组织、个体工商户等 |
| **金融机构** | 商业银行、财务公司等 |
