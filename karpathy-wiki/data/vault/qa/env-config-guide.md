## 问题

如何配置环境变量？请详细说明步骤。

## 答案

在项目根目录创建 `.env` 文件，按 `KEY=VALUE` 格式写入配置，重启服务后生效。生产环境建议用 [[dotenv]] 库加载，避免硬编码。

## 详细步骤

1. 在项目根目录创建 `.env` 文件
2. 按 `KEY=VALUE` 格式逐行写入配置项
3. 在代码中通过 `dotenv` 库加载 `.env` 文件
4. 通过 `process.env.KEY` 读取配置值
5. 重启服务使配置生效

## 最佳实践

- 切勿将 `.env` 文件提交到版本控制系统（已在 `.gitignore` 中排除）
- 为不同环境（开发/测试/生产）准备独立的 `.env` 文件
- 使用 `dotenv` 库加载环境变量，避免硬编码敏感信息
- 在生产环境中优先使用平台原生的环境变量机制（如 Docker/K8s ConfigMap）
