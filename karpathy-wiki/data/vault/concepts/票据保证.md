# 票据保证

## 概述

电票保证是指**票据上记载的债务人以外的第三人**保证该票据获得付款的票据行为。保证人通过作出保证，增强票据的信用等级。

## 四种保证类型

### 1. 出票保证
- **时机**：票据完成出票信息登记后、提示承兑前
- **流程**：出票人发起保证申请 → 保证人作出保证 → 出票保证完成 → 提示承兑申请

### 2. 承兑保证
- **时机**：票据完成提示承兑后、提示收票前
- **流程**：承兑人发起保证申请 → 保证人作出保证 → 承兑保证完成

### 3. 背书保证
- **时机**：票据完成提示收票后、贴现前
- **流程**：持票人发起保证申请 → 保证人作出保证 → 背书保证完成

### 4. 贴现保证
- **时机**：票据完成贴现后、首次交易或质押前
- **流程**：贴入人发起保证申请 → 保证人作出保证 → 贴现保证完成

## 完整流程示意

```
出票信息登记 → 保证申请 → 保证申请应答 → 提示承兑申请
出票保证完成↓
提示承兑应答（承兑人）
↑↓
提示收票应答 ← 提示收票申请 ← 保证申请应答 ← 保证申请（承兑保证）
持票人保证人（背书保证）
贴入人保证人（贴现保证）
```

## 交互流程

1. 申请人发起保证申请
2. 参与者服务机构转发申请
3. 票交所校验并转发申请
4. 保证人作出应答
5. 参与者服务机构转发应答结果
6. 票交所返回应答结果

- 保证是[[中国票据业务系统]]中票据流转的重要环节
- 票据状态在保证/背书/贴现等环节分别流转
