# 参与者接入

## 概述

参与者接入是[[中国票据业务系统]]中各类业务主体（企业和金融机构）加入系统的入口机制，涵盖业务参与者、参与者服务机构和企业信息备案等环节。

## 参与者类型

### 业务参与者
- **直接参与者**：金融机构、非法人产品等
- **间接参与者**：通过参与者服务机构接入的企业

### 参与者服务机构
- **金融机构**（开户行）
- **供应链平台**（供票平台）

## 接入流程

```
发起申请 → 提交申请 → 转发申请 → 应答 → 应答结果 → 票据权属的变更
                                                    → 资金的清算结算
```

1. 业务参与者发起申请
2. 提交给其对应的参与者服务机构
3. 服务机构转发至票交所
4. 票交所应答并转发应答结果
5. 实现资产结算和资金结算

## 企业信息备案机制

### 流程

1. **参与者服务机构审核并报送**企业信息至票交所
2. **票交所校验**：将企业名称与工商登记信息对比
3. 检查一致则通过并记录入库；不一致则退回更正
4. 信息更新维护

### 备案要点

- 必选信息包括：**企业名称、统一社会信用代码、账号、账户名称、开户行行号**，其他为可选信息
- 支持报备**多组账户信息**
- 企业名称与统一社会信用代码应与**营业执照**和**国家企业信息公示系统**中相关信息保持一致
- 企业在**多个参与者服务机构**（开户行、供票平台）办理票据业务的，其服务机构需分别为企业报备相关信息
- 各参与者服务机构分别报备，互不影响
- 存在延时返回的可能

### 办理条件

参与者服务机构在为企业开通票据业务权限前，应向票交所报备企业的基本信息和结算账户等信息。

所需文件：**票据业务承诺函 + 电子商业汇票业务服务协议**

## 资金结算规则

### 间接参与者
- 通过**结算账户开户行**办理资金的结算
- 金融机构作为服务机构 → 使用其在该金融机构的结算账户
- 供应链平台作为服务机构 → 使用其在结算账户开户行的结算账户

### 直接参与者
- 金融机构、非法人产品等直接参与者
- 通过**大额支付系统**或**开立在票交所的资金账户**进行资金清算结算

## 关联

- 参与者接入是使用[[中国票据业务系统]]的前提条件
- 与[[票据账户主动管理]]机制配合实现账户权限控制
