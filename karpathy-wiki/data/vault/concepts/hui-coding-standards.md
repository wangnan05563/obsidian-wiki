# HUI 编码规范

## 概述

HUI 编码规范是恒生电子 [[hui-framework]] 项目配套的完整前端编码规范体系，涵盖 HTML/TEMPLATE、CSS/LESS/SASS、JavaScript/ES6、Vue 及图像约定等多个技术栈的规范要求。

## 1. HTML/TEMPLATE 开发规范

### 通用语法
- **【强制】** 缩进使用两个空格代替 Tab
- **【强制】** 嵌套元素应当缩进一次（两个空格），同层级缩进保持一致
- **【强制】** 将每个块元素、列表元素或表格元素都放在新行
- **【强制】** 属性定义使用双引号，不要使用单引号
- **【强制】** 不要省略可选的结束标签（如 `</li>` 或 `</body>`）
- **【强制】** 特殊符号使用 HTML 字符实体

### HTML5 Doctype
每个 HTML 页面第一行必须使用标准 HTML5 Doctype：
```html
<!DOCTYPE html>
```

### 语言属性
- **【推荐】** 在 `<html>` 标签上使用 `lang` 属性，中文页面推荐：`<html lang="zh-CN">`

### 字符编码
- **【强制】** 使用 UTF-8 编码：`<meta charset="UTF-8">`

### 引入 CSS 和 JavaScript
- **【推荐】** 引入 CSS 无需指明 type，因为 `text/css` 为默认值
- **【推荐】** 引入 JavaScript 无需指明 type，因为 `text/javascript` 为默认值

### 减少标签数量
- **【推荐】** 在保证功能与可维护性的前提下，尽量减少 HTML 标签数量

### 属性顺序
- **【推荐】** HTML 属性应按特定顺序排列，以保证可读性

### 语义化
- **【推荐】** 根据 HTML 元素的语义选择使用合适的标签

## 2. CSS/LESS/SASS 开发规范

### 命名规范
- 使用有意义的命名，避免使用无意义的缩写
- 类名使用小写字母，单词间用连字符（`-`）分隔

### 语法
- **【强制】** 每个声明块的右大括号前应换行
- **【强制】** 每个声明单独一行
- **【推荐】** 使用简写属性值

### 代码风格
- **【强制】** 使用 2 个空格缩进
- **【强制】** 选择器与左大括号之间留一个空格
- **【强制】** 属性名冒号后留一个空格

### 样式兼容性
- 注意不同浏览器的兼容性问题，合理使用浏览器前缀

### 选择器权重
- 了解 CSS 选择器权重计算规则，避免样式覆盖混乱

### 声明顺序
- **【推荐】** 按特定逻辑顺序排列 CSS 声明（定位 → 盒模型 → 排版 → 视觉 → 动画等）

### 字体规则
- **【强制】** 中文字体使用系统默认字体，英文字体优先

## 3. 图像约定

- **【推荐】** 图像需进行压缩处理
- 背景图与前景图分开管理
- **【推荐】** 使用 CSS Sprite 合并小图标以减少 HTTP 请求

## 4. JavaScript/ES6 开发规范

### 命名
- 变量名使用 camelCase（小驼峰）
- 常量使用全大写 + 下划线
- 类名使用 PascalCase（大驼峰）
- 函数名使用 camelCase

### 语法
- **【强制】** 使用 `const` 和 `let` 代替 `var`
- 使用箭头函数简化回调
- 使用模板字符串拼接字符串

### 代码风格
- **【强制】** 语句末尾使用分号
- **【强制】** 使用 2 个空格缩进

### 数组、对象
- 使用字面量创建数组和对象
- 使用解构赋值

### 使用 null
- **【推荐】** 明确表示空值时使用 `null`，未赋值时使用 `undefined`

### 文档注释
- 函数、类等应使用 JSDoc 风格的文档注释

## 5. Vue 开发规范

### .vue 命名规范
- 组件文件名使用 PascalCase
- 基础组件以特定前缀命名（如 Base、App、V 等）

### 文件夹命名规范
- 文件夹使用 kebab-case（短横线分隔）

### 语法
- 组件内不能使用 `v-html` 防止 XSS 攻击
- **【强制】** 组件 `data` 必须是函数
- **【强制】** `v-for` 必须配合 `key` 使用
- 优先使用计算属性而非复杂的模板表达式

### 组件/实例选项顺序
- 按官方推荐顺序排列组件选项：`name` → `components` → `props` → `data` → `computed` → `watch` → 生命周期钩子 → `methods`

### 元素特性顺序
- `v-for` → `v-if` → `v-bind` → `v-on` → `v-model`

### 单文件组件顶级元素顺序
- `<template>` → `<script>` → `<style>`
