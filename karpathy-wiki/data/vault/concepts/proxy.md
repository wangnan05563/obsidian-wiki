# Proxy

**Proxy**（代理）是一种中间服务器，充当客户端和目标服务器之间的中转站，用于转发请求和响应。

## 概述

代理服务器可以用于多种目的，包括匿名访问、内容过滤、缓存加速、跨域访问等。

## 类型

- 正向代理（Forward Proxy）
- 反向代理（Reverse Proxy）
- 透明代理（Transparent Proxy）
