# 票据流转

票据流转是[[中国票据业务系统]]中票据签发后的核心业务环节，涵盖**背书、质押、保证、贴现、交易与再贴现**等多项票据行为。

## 背书

**定义**：持票人将票据权利依法转让给他人的票据行为（本节指企业间转让背书）。

**流程**：
```
背书转让申请 → 背书转让应答 → 背书成功
```
- 持票人（背书人）操作背书转出
- 收票人（被背书人）作出同意应答
- 完成票据权利交割

## 质押及质押解除

**质押**是指票据持票人以其持有的未到期的票据通过质押背书形式为自己或第三人的债务提供抵押担保。

### 质押
```
质押申请 → 质押应答 → 质押成功
```
- 出质人：票据持票人
- 质权人：收票人/债权人

### 质押解除
```
质押解除申请 → 质押解除应答 → 质押解除成功
```
- 主债务已经履行完毕的，质权人按约定解除质押
- 出质人（原持票人）、质权人角色互换

## 保证

**定义**：票据上记载的债务人以外的第三人保证该票据获得付款的票据行为。

### 四种保证类型

| 类型 | 触发时机 | 发起人 |
|------|---------|-------|
| 出票保证 | 完成出票信息登记后、提示承兑前 | 出票人 |
| 承兑保证 | 完成提示承兑后、提示收票前 | 承兑人 |
| 背书保证 | 完成提示收票后、贴现前 | 持票人 |
| 贴现保证 | 完成贴现后、首次交易或质押前 | 贴入人 |

## 贴现

**定义**：持票人在票据到期日前，为了取得资金贴付一定利息将票据权利转让给金融机构的行为。

### 贴现类型
- **买断式贴现**：票据权利完全转让
- **回购式贴现**：可赎回的贴现

### 回购式贴现赎回
原贴现申请人、原贴入人按照协议约定，在赎回开放期赎回票据：
```
赎回申请 → 赎回应答 → 回购式贴现赎回成功
```

## 交易与再贴现

### 转贴现
卖出方将**未到期的已贴现票据**向买入方转让的交易行为。

### 质押式回购
正回购方将票据出质给逆回购方融入资金，双方约定在未来某一日期由正回购方按约定金额向逆回购方返还资金、逆回购方向正回购方返还原出质票据。

### 买断式回购
正回购方将票据卖给逆回购方的同时，双方约定在未来某一日期，正回购方再以约定价格从逆回购方买回票据。

### 再贴现（质押式回购）
再贴现申请人将票据出质给**人民银行**融入资金，双方约定在未来某一日期由再贴现申请人按约定金额向人民银行返还资金、人民银行向再贴现申请人返还原出质票据。

### 交易方式

**对话报价**：
- **一对一模式**：对手方机构和交易员明确且唯一
- **意向询价**：一对多模式，可选择全市场或群组

## 票交所转发流程

所有票据流转业务均通过参与者服务机构与票交所交互：
1. 申请人发起申请
2. 参与者服务机构转发申请
3. 票交所校验并转发申请
4. 接收人应答
5. 票交所转发应答结果
