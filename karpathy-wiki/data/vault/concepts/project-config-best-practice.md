# 项目配置最佳实践

项目配置管理是软件开发中的重要环节，涵盖环境变量、配置文件、密钥管理等多个方面。

## 核心理念

1. **代码与配置分离**：配置不应硬编码在源码中
2. **环境差异化**：开发/测试/生产环境使用不同配置集
3. **最小权限原则**：仅暴露必要的配置项

## 常用方案

| 方式 | 适用场景 | 安全等级 |
|------|---------|---------|
| `.env` 文件 | 本地开发 | 中（需加入 `.gitignore`） |
| 系统环境变量 | 服务器部署 | 中 |
| 密钥管理服务（Vault/Secrets Manager） | 生产环境 | 高 |
| K8s Secret / Docker Secrets | 容器化部署 | 高 |
