## 概述

`.env` 文件规范定义了以文件形式管理环境变量的标准格式和最佳实践。该规范被主流语言和框架广泛采用，如 Node.js（dotenv）、Python（python-dotenv）、Ruby 等。

## 格式约定

```
# 注释以 # 开头
KEY=VALUE
DB_HOST=localhost
DB_PORT=5432
# 带引号的值
APP_NAME="My App"
```

### 规则

1. 每行一个键值对，格式为 `KEY=VALUE`
2. `=` 前后**不应有空格**
3. 值可以不加引号；带空格的值应使用双引号包裹
4. 以 `#` 开头的行为注释
5. 空行会被忽略

## 安全注意事项

- `.env` 文件应加入 `.gitignore`，**永远不要提交到版本控制**
- 对于敏感信息（密钥、密码），建议配合秘密管理服务使用
