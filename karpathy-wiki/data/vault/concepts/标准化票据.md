# 标准化票据

**标准化票据**是[[上海票据交易所]]推出的一项创新产品，指将票据资产进行标准化处理后，形成可在市场流通交易的证券化产品。

## 概述

标准化票据旨在盘活票据资产，提升票据市场的流动性和透明度，拓宽中小企业融资渠道。它是上海票交所"创新产品"板块的核心组成部分之一。

## 相关创新产品体系

上海票交所创新产品矩阵包括：
- **标准化票据** — 票据资产标准化
- **票付通** — 票据支付便利化
- **贴现通** — 票据贴现信息撮合
- **供应链票据** — 供应链场景票据
- **跨境平台** — 跨境票据服务
- **票据综合服务平台** — 综合服务入口

## 意义

标准化票据的推出有助于：
1. 提升票据资产的可交易性和流动性
2. 降低企业融资成本
3. 扩大票据市场参与主体范围
4. 促进票据市场与债券市场互联互通
