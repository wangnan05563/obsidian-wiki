# 票据业务系统报文（MEM报文体系）

## 概述

MEM（Member）报文体系是 [[中国票据业务系统直连接口规范（业务主体分册）]] 中定义的参与者管理类 XML 报文集合，用于业务参与者信息的通知、维护、查询等操作。这些报文遵循 [[票据报文交换标准]] 中定义的通用报文结构、编号规则和加密规范。

## 报文列表

### 通知类报文（广播）

| 报文 | 名称 | 触发场景 |
|------|------|---------|
| MEM.001.002 | 业务办理渠道信息通知报文 | 场务创建或修改业务办理渠道信息时，向所有直连渠道广播 |
| MEM.002.002 | 机构参与者信息通知报文 | 场务或渠道修改机构参与者信息时广播 |
| MEM.003.002 | 机构参与者交易员信息通知报文 | 交易员信息变更时广播 |
| MEM.004.002 | 机构参与者新原关系通知报文 | 机构承接关系建立时广播 |
| MEM.005.002 | 创建修改机构参与者通知报文 | 机构参与者创建或修改时通知 |

## 通用报文结构

每个 MEM 报文均包含以下公共要素：

- **报文标识** `<MsgId/>` — 含报文标识号 `<Id/>` 和报文时间 `<CreDtTm/>`
- **业务主体信息** — 按报文类型不同而变化
- **扩展属性信息** `<ExtInfs/>` — 用于传递扩展字段（属性值类型为 UnType）

## 报文处理规则特点

1. **接收方按规范解析** — 参与者收到报文后按规范解析并更新自身系统
2. **清算模式关联** — 清算模式为模式二的渠道需处理 ECDS 线上清算权限字段
3. **承接关系不调整历史** — 建立承接关系后不调整票据基本信息和历史行为信息
4. **扩展属性通用化** — V1.3 起扩展信息组件字段属性值类型统一为 UnType
