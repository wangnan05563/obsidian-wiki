# 票据质押

## 概述

质押是担保的一种情形。票据持票人以其持有的**未到期的票据**通过质押背书形式为自己或第三人的债务提供抵押担保的方式。

## 质押

票据的持票人为了给债权提供担保，以该票据为债权人设立质权的行为。

### 业务流程

```
质押申请 → 质押应答 → 质押成功
（出质人）   （质权人）
```

## 质押解除

主债务已经履行完毕的，质权人按约定解除质押。

### 业务流程

```
质押解除申请 → 质押解除应答 → 质押解除成功
（质权人）       （出质人）
```

## 交互流程（质押/质押解除通用）

1. 申请人发起申请
2. 参与者服务机构转发申请
3. 票交所校验并转发申请
4. 接收人应答
5. 参与者服务机构转发应答结果
6. 票交所返回应答结果

## 角色定义

- **出质人**：持有票据并提供质押担保的一方（即持票人）
- **质权人**：接受质押担保的债权人

## 关联

- 质押是[[中国票据业务系统]]中票据流转（存续期业务）的组成部分
- 质押期间票据状态为"已质押/待赎回"
