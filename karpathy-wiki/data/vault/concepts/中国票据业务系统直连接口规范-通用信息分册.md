# 中国票据业务系统直连接口规范（通用信息分册）

## 概述

《中国票据业务系统直连接口规范——通用信息分册》是由 [[上海票据交易所]] 发布的票据业务系统直连接口技术规范文档。本分册定义了票据业务系统中**通用业务场景**的报文流程与 XML 报文格式，涵盖通用业务撤销、影像/附件管理、通用通知、票据信息查询与查验、冻结/解除冻结登记、贸易信息登记与查询、票据信息补充维护及参与者票据清单查询等功能。

当前版本为 **V1.4**（2026年6月），是自 V1.0（2021年5月）以来经过七次修订的稳定版本。

## 业务场景报文流程

本规范定义了以下 **11 类通用业务场景**的报文流程：

### 1.1 通用业务撤销
支持对已提交但尚未最终确认的业务申请进行撤销操作。

### 1.2 影像/附件上传
参与者向票交所上传影像文件或业务附件，支持批量上传。

### 1.3 影像查询
参与者查询已上传的影像文件信息。

### 1.4 附件查询
参与者查询已上传的附件信息，包括附件批次号等。

### 1.5 通用通知
票交所向参与者发送各类业务通知，涵盖多个通知场景（NT05、NT06、NT07、NT10、NT11、NT12等）。

### 1.6 票据信息查询
参与者查询指定票据的详细信息。

### 1.7 票据查验
照票人提交票据查验请求，查验金额可小于或等于持有的票据包金额；查验不改变票据状态和权利人。

### 1.8 冻结/解除冻结登记申请
对票据进行冻结或解除冻结的登记操作，通知持票人。

### 1.9 贸易信息登记申请
登记票据交易的贸易背景信息，包括贸易方式、合同类型、发票信息等。

### 1.10 贸易信息查询
查询已登记的贸易背景信息。

### 1.11 票据信息补充维护申请
对票据信息进行补充维护，包括金融机构标注信息维护等功能。

### 1.12 参与者票据清单查询申请（V1.4新增）
查询参与者持有的票据清单信息，包含申请与应答两个报文。

## 报文体系（CIM报文）

本规范定义 **20 种 XML 报文**，均以 **CIM**（Common Information Message）为前缀，涵盖通用业务的申请、确认、撤销、转发、应答、通知、查询等全流程。

### 业务确认与撤销类

| 报文编号 | 名称 | 功能说明 |
|---------|------|---------|
| CIM.001.002 | 通用业务确认报文 | 票交所处理完成后向参与者发送确认，含出票信息登记返回票据号等功能 |
| CIM.002.002 | 通用业务撤销报文 | 参与者发起业务撤销申请，含代理签章和风险票据状态控制规则 |
| CIM.003.002 | 通用业务转发报文 | 票交所向相关参与者转发业务申请 |
| CIM.004.002 | 通用业务应答报文 | 参与者对转发业务进行应答，含追索分包规则、清算时序控制 |

### 影像与附件管理类

| 报文编号 | 名称 | 功能说明 |
|---------|------|---------|
| CIM.006.002 | 影像上传申请报文 | 参与者上传影像文件 |
| CIM.008.002 | 影像查询申请报文 | 查询已上传影像信息 |
| CIM.009.002 | 影像查询应答报文 | 返回影像查询结果 |
| CIM.012.002 | 附件上传申请报文 | 上传业务附件，含附件名称字段 |
| CIM.014.002 | 附件信息查询申请 | 查询附件信息 |
| CIM.015.002 | 附件查询应答报文 | 返回附件查询结果 |

|---------|------|---------|
| CIM.017.002 | 票据信息补充维护申请报文 | 原再贴现补充登记/修改申请报文，现支持金融机构标注信息维护，支持承兑环节 |

## 关键特性

### 票据查验
- 照票人提交的票据查验金额可以小于或等于其持有的票据包金额
- 票据查验**不改变**票据状态和票据权利人
- 查验金额小于票据包金额时，不对票据包进行分包处理

### 扩展信息组件
- 支持产业属性集合信息
- 支持票据追索权范围信息
- 支持票据标记信息（V1.4新增）
- 字段属性值类型为 `UnType`

### 时序控制
- 涉及清算业务应答时需遵循时序控制规则
- 批量背书成功后向背书人下发子票区间（V1.4新增）
