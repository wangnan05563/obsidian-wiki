# 票据全生命周期业务流程

## 概述

[[中国票据业务系统]] 承载票据的全生命周期业务，覆盖三个主要阶段：**票据签发**、**票据流转**和**票据到期处理**。

## 一、票据签发

票据签发包括三个业务子流程：

### 1. 出票信息登记
出票人基于支付需要，进行票据信息出票登记的行为。

### 2. 提示承兑
出票人出示票据，并要求付款人承诺付款的行为。

### 3. 提示收票
出票人向收款人交付电票，发起提示收票申请，由收款人作出应答。

### 4. 撤票
出票人在电票出票信息登记成功后、收款人对提示收票申请应答同意前，可以对电票作未用退回处理。

**流程**：出票信息登记 → 提示承兑申请 → 提示承兑应答 → 提示收票申请 → 提示收票应答 → 票据签发成功

## 二、票据流转

### 1. 背书
持票人（背书人）将票据权利依法转让给他人的票据行为。

**流程**：背书转让申请 → 背书转让应答 → 背书成功

### 2. 质押及质押解除
- **质押**：持票人（出质人）为债权提供担保，以票据为债权人（质权人）设立质权
- **质押解除**：主债务履行完毕后，质权人按约定解除质押

**流程**：质押申请 → 质押应答 → 质押成功
**解除流程**：质押解除申请 → 质押解除应答 → 质押解除成功

### 3. 保证
票据上记载的债务人以外的第三人保证该票据获得付款的票据行为。包括四种类型：

| 保证类型 | 发起时机 | 发起人 |
|---------|---------|--------|
| 出票保证 | 出票信息登记后、提示承兑前 | 出票人 |
| 承兑保证 | 提示承兑后、提示收票前 | 承兑人 |
| 背书保证 | 提示收票后、贴现前 | 持票人 |
| 贴现保证 | 贴现后、首次交易或质押前 | 贴入人 |

### 4. 贴现
持票人在票据到期日前，为取得资金贴付利息将票据权利转让给金融机构的行为。

**类型**：
- **买断式贴现**：直接转让
- **回购式贴现**：原贴现申请人可在赎回开放期赎回票据

**流程**：贴现申请 → 贴现申请应答 → 贴现成功

### 5. 交易与再贴现

| 类型 | 定义 |
|-----|------|
| **转贴现** | 卖出方将未到期的已贴现票据向买入方转让 |
| **质押式回购** | 正回购方将票据出质给逆回购方融入资金，约定未来返还 |
| **买断式回购** | 正回购方将票据卖给逆回购方，约定未来买回 |
| **再贴现** | 再贴现申请人将票据出质给人民银行融入资金，约定未来返还 |

**交易方式**：
- **对话报价**：一对一模式 / 一对多模式（全市场或群组）
- **意向询价**：匿名点击，价格优先、时间优先
- **点击成交**：包含全部交易要素，点击成交或提交票据后成交

## 三、票据到期处理

### 提示付款
持票人向承兑人请求付款的行为，分三种类型：

| 类型 | 触发时机 | 发起方式 |
|-----|---------|---------|
| **提前提示付款** | 票面到期日前 | 持票人手动发起 |
| **到期提示付款** | 到期日当天 | 票交所根据持票人授权自动发起 |
| **期后提示付款** | 到期提示付款被拒付后 | 持票人手动再次发起 |

**应答规则**：
- 银票 & 财票：提前提示付款由承兑人应答；到期及期后提示付款自动应答为同意
- 商票：均需由承兑人手动应答
- 超过 17:14 分应答为同意的票据，下一工作日进行资金清算
- 日终未应答视作应答拒绝

### 追索
提示付款被拒绝兑付后，持票人可发起追索。
