# 中国票据业务系统

**中国票据业务系统**是由[[上海票据交易所]]建设和运营的全国统一票据交易平台，提供票据交易、登记托管、清算结算等全流程服务。本文档概述其直连接口规范——**票据交易分册**的核心内容。

## 概述

中国票据业务系统直连接口规范是市场参与者（会员机构）与票交所系统进行直连对接的技术标准文档。其中**票据交易分册**主要规范了票据交易环节的报文格式、业务流程和技术要求。

## 接口规范版本

当前最新版本为 **V1.4**（2026年6月发布）。

## 核心业务场景

系统支持以下主要交易业务场景的报文流程：

### 1. 对话报价
- 一次/两次/多次对话报价
- 交易要素或票据锁定失败处理
- 成交要素校验或票据要素校验失败处理
- 超时终止处理

### 2. 意向询价
- 意向询价发起、修改、撤销
- 适用于转贴现、质押式回购、买断式回购等业务

### 3. 再贴现业务
- 再贴现业务申请审批（人行审批）
- 再贴现授信通知
- 再贴现受理关系通知
- 再贴现质押式回购和买断式回购

### 4. 转贴现点击成交
- 全部成交、部分成交
- 报价撤销（未成交/部分成交后）

### 5. 质押式回购匿名点击
- 匿名点击发送、撤销
- 成交提票成功/失败
- 提票超时处理

### 6. 授信关系维护

## 报文体系（XML格式）

系统定义了 **38类报文**（CES.001.002 ~ CES.038.002），涵盖从报价发起、转发、成交通知到撤销等全流程。

### 主要报文分类

| 报文编号 | 报文名称 | 业务类型 |
| --- | --- | --- |
| CES.001.002 | 转贴现对话报价发送修改申请报文 | 转贴现 |
| CES.002.002 | 转贴现对话报价转发报文 | 转贴现 |
| CES.003.002 | 转贴现成交通知报文 | 转贴现 |
| CES.004~006 | 质押式回购对话报价系列报文 | 质押式回购 |
| CES.007~009 | 买断式回购对话报价系列报文 | 买断式回购 |
| CES.010.002 | 交易业务确认报文 | 通用 |
| CES.011~012 | 对话报价应答/终止通知报文 | 通用 |
| CES.013~019 | 意向询价系列报文 | 转贴现/质押/买断 |
| CES.020~027 | 再贴现系列报文 | 再贴现 |
| CES.028~032 | 转贴现点击成交系列报文 | 转贴现 |
| CES.033~037 | 匿名点击系列报文 | 质押式回购 |
| CES.038.002 | 授信信息维护申请报文 | 授信管理 |

### 报文通用结构

每个报文包含以下核心组件：
- **报文标识**（MsgId）：报文标识号 + 报文时间
- **原报文标识**（OrgnlMsgId）：用于关联前序报文
- **业务数据**：根据业务类型包含不同的字段组合
- **扩展组件**：用于有限追索服务等特殊场景

## 关键字段说明

规范中定义了大量业务字段，其中重要的包括：

- **信用主体相关字段**：在 V1.4 中，"信用主体类型/信用主体"调整为"贴现行类型/贴现行机构代码"
- **报价单操作标识**（QuoteOp）：标识报价的新增、修改等操作
- **业务类型**（BusiType）：区分转贴现、质押式回购、买断式回购
- **交易方向**（TrdDir）：买入/卖出
- **部分成交选项**（SubDeal）：是否允许部分成交
