# 票据分包

票据分包是 [[中国票据业务系统]] 中电子商业汇票的一种特性，允许持票人将持有的票据包按需拆分使用。

## 票据信息要素

新系统签发的电子商业汇票具有两个核心要素：

### 票据（包）号
票据（包）的唯一且不变的标识号码，共 30 位：

| 字段 | 位数 | 说明 |
|------|------|------|
| 票据种类标识 | 1 位 | 5、6、7、8 |
| 支付系统行号 | 12 位 | |
| 出票信息登记日期 | 8 位 | |
| 当天流水号 | 8 位 | |
| 校验码 | 1 位 | |

### 子票区间
- **标准金额票据包**：以子票区间标识，显示起始序号和终止序号（如 "1-2000000"）
- **固定金额票据**：子票区间为 "0"

## 分包机制

### 基本规则
- 业务发起时，若申请金额小于持有票据包金额，即实现分包流转
- 票据（包）号不变，子票区间随分包变化

**示例**：
- 持票人 A 持有票据包：号码 510373100297620230420000000083，子票区间 1-2000000，金额 20000
- 向企业 B 发起背书 10000 元 → 分包后：
  - 持票人 A 保留：子票区间 1000001-2000000，金额 10000
  - 企业 B 获得：子票区间 1-1000000，金额 10000

### 特点

| 特点 | 说明 |
|------|------|
| 分包随业务发起 | 业务申请金额 < 持有票据包金额时自动分包流转* |
| 灵活分包 | 支持最小分包金额为 0.01 元 |
| 分包不可逆 | 分包后不支持重新合并 |

*例外：（贴现前）追索与票据查验不支持分包

## 支持分包的业务环节

| 支持分包 | 不支持分包 |
|---------|-----------|
| 出票/承兑/收票 | 保证（贴现前） |
| 质押 | 票据交易（转贴现、回购） |
| 背书 | 再贴现 |
| 贴现 | 线上追索 |
| 提示付款 | |
| 保证（仅贴现前除外） | |

## 供应链票据

[[中国票据业务系统]] 在签发端推出供应链票据，票据种类标识为 7、8，通过供应链平台接入。
