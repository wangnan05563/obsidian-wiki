# 票据分包

票据分包是中国票据业务系统（[[中国票据业务系统]]）中的核心机制，允许将一个**标准金额票据包**按实际需要分割为多个子票据包进行流转。

## 票据包构成

- 票据包由**若干标准金额票据**组成，每张标准金额票据以**子票号**标识区分，自1开始顺序编号
- 票据包中所有单张标准金额票据的集合以**子票区间**标识，显示本包票据的起始序号和终止序号
- **票据包金额** = 标准金额票据张数 × 标准金额
- **固定金额票据**的子票区间为"0"

## 票据（包）号结构

票据（包）号共30位，构成如下：

| 字段 | 位数 |
|------|------|
| 票据种类标识（5、6、7、8） | 1位 |
| 支付系统行号 | 12位 |
| 出票信息登记日期 | 8位 |
| 当天流水号 | 8位 |
| 校验码 | 1位 |

## 票据信息要素

新系统签发的电子商业汇票具有两个核心要素：
- **票据（包）号**：唯一且不变的标识号码
- **子票区间**：标示分包状态

分包使用时，票据（包）号不变，**子票区间**随分包情况变化。

## 分包特点

### 灵活分包
- 根据实际需要分包使用
- 支持**最小分包金额为0.01元**

### 分包随票据业务发起
- 业务发起时，业务申请金额小于持有票据包金额的，即实现分包流转
- **例外**：贴现前追索与票据查验不支持分包

### 分包不可逆
- 票据包分包后**不支持重新合并**

## 支持票据分包的环节

支持的环节包括：
- 出票/承兑/收票
- 背书
- 质押
- 贴现
- 票据交易（转贴现、回购）
- 再贴现
- 提示付款
- 追索
- 保证

不支持的环节：
- 贴现前追索
- 票据查验

## 示例

票据包号 `510373100297620230420000000083`，子票区间 `1-2000000`，票据包金额 `20000`。

向企业B发起转让背书（背书金额10000）时，分包为：
- 子票区间 `1-1000000`，票据包金额 `10000`（持票人A保留）
- 子票区间 `1000001-2000000`，票据包金额 `10000`（转让给持票人B）
