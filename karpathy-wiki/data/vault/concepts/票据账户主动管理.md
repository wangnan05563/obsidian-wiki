# 票据账户主动管理

票据账户主动管理是 [[上海票据交易所]] 为防范企业账户被冒用风险而推出的服务机制。

## 背景

近年来，多家国企相继发布公告，声称有人冒用其身份开设银行账户并使用该账户开具虚假电子商业承兑汇票，并表示不对该账户和相关电子票据承担责任。

## 核心机制

### 定义
企业委托一个具有电票功能的结算账户的开户机构（开户银行或所属集团财务公司）在 [[中国票据业务系统]] 登记该客户所有可办理电票业务的结算账户信息的服务。

```
客户 → 委托 → 开户机构 → 登记 → 上海票据交易所
```

### 功能
- 企业在多个金融机构办理电票业务的，可通过指定的一个金融机构对其在各机构账户的业务权限进行关闭、删减等操作
- 实现企业对账户的自主管理、穿透控制
- 有效防范企业被不法分子假冒身份开立虚假账户并办理票据业务的风险
