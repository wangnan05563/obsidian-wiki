# XML Schema 文件命名规则

## 概述

该目录下存放 [[XML Schema]] 文件，文件名遵循"报文编号.xml"的命名规则。

## 命名规则

- **格式**：报文编号.xml
- **示例**：若报文编号为 `MSG001`，则对应文件为 `MSG001.xml`
