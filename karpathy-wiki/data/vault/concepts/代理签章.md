# 代理签章

## 概述

代理签章机制允许金融机构在企业客户的委托授权下，代企业发起票据业务申请或应答，并使用金融机构自身的电子签名信息。

## 适用条件

企业办理票据业务申请或业务应答时：
- **自行签章**：可自行发起并提供自己的电子签名信息
- **代理签章**：金融机构与企业签订协议后，金融机构可代理企业发起并提供金融机构自身的电子签名信息

## 适用代理签章的业务类型

| 业务种类 | 申请 | 应答 |
|---------|------|------|
| 出票 | √ | 不涉及 |
| 承兑 | √ | ✗ |
| 收票 | √ | √ |
| 撤票 | ✗ | 不涉及 |
| 背书 | √ | √ |
| 质押 | / | / |
| 质押解除 | √ | √ |
| 保证 | √ | ✗ |
| 贴现 | √ | 不涉及 |
| 提示付款 | √ | √ |
| 追索 | √ | √ |

## 案例：代理签章+线上清算

代理签章与线上资金清算结合使用，便利企业用票，提升业务处理效率。
