# 代理签章

代理签章是 [[中国票据业务系统]] 支持的一项便利企业用票的机制，允许金融机构在签订协议后代理企业发起并提供金融机构自身的电子签名信息。

## 适用业务

| 业务种类 | 申请 | 应答 |
|---------|------|------|
| 出票 | √ | 不涉及 |
| 承兑 | √ | × |
| 收票 | √ | √ |
| 撤票 | × | 不涉及 |
| 背书 | √ | √ |
| 质押/质押解除 | √ | √ |
| 保证 | √ | × |
| 贴现 | √ | 不涉及 |
| 提示付款 | √ | √ |
| 追索 | √ | √ |

## 两种模式

企业办理票据业务申请或业务应答时：
1. **自行发起**：企业自行发起并提供自己的电子签名信息
2. **代理签章**：金融机构与企业签订协议后，金融机构可代理企业发起并提供金融机构自身的电子签名信息

## 典型案例

代理签章 + 线上清算
