## 概述

环境变量管理是应用配置的核心环节，良好的实践能提升应用的安全性、可移植性和可维护性。

## 核心原则

### 1. 配置与代码分离
将配置信息（数据库连接串、API 密钥、服务端口等）从代码中剥离，通过环境变量注入。

### 2. 敏感信息保护
- 密钥、密码、Token 等敏感信息仅通过环境变量传入，不硬编码。
- `.env` 文件加入 `.gitignore`，防止意外提交。
- 生产环境应使用密钥管理服务（如 AWS Secrets Manager、Vault）。

### 3. 多环境支持
- **开发环境**: `.env.development`，可包含调试配置
- **测试环境**: `.env.test`，使用测试专用资源
- **生产环境**: `.env.production`，严格管理访问权限

### 4. 缺省值与验证
- 为每个配置项提供合理的默认值。
- 启动时验证必要配置是否完整，缺失时立即报错。
