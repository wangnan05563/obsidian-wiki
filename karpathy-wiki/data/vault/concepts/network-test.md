# Network Test

**Network Test**（网络测试）是用于验证网络功能、性能和连通性的测试方法集合。

## 概述

网络测试涵盖从基础连通性检查到复杂的性能基准测试等多个层面，是网络运维和开发的重要环节。

## 常见测试类型

- 连通性测试（Ping/Traceroute）
- 带宽测试
- 延迟测试
- 代理测试（如 [[proxy-test-1]]）
