# PKM报文体系

PKM（Public Key Management）报文体系是 [[上海票据交易所]] 定义的用于票据业务系统直连接口安全控制的报文系列，涵盖加密公钥申请、登记与密钥更新等核心流程。

## 报文列表

### PKM.001.001 — 加密公钥申请报文

- **方向：** 业务办理渠道 → 票据业务系统
- **功能：** 申请票据业务系统的加密公钥
- **关键字段：** MsgId（报文标识号、时间）、MbrId（渠道代码）

### PKM.002.001 — 加密公钥申请应答报文

- **方向：** 票据业务系统 → 业务办理渠道
- **功能：** 返回票据业务系统加密公钥
- **关键字段：** OrgnlMsgId（原报文标识）、BizCtrlInf（处理结果）、CPEPk（SM2加密公钥）

### PKM.003.001 — 加密公钥登记申请报文

- **方向：** 业务办理渠道 → 票据业务系统
- **功能：** 业务办理渠道登记自身加密公钥
- **关键字段：** MbrId（渠道代码）、MbrPk（SM2加密公钥）
- **前置条件：** 已成功完成 PKM.001.001 → PKM.002.001 流程

### PKM.004.001 — 密钥更新广播报文

- **方向：** 票据业务系统 → 业务办理渠道
- **功能：** 票据业务系统密钥更新广播
- **关键字段：** PukCpeEnc（新SM2加密公钥）
