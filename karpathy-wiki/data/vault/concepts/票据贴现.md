# 票据贴现

## 概述

贴现是持票人在**票据到期日前**，为了取得资金贴付一定利息将票据权利转让给金融机构的行为。

贴现包括**买断式贴现**和**回购式贴现**两种方式。

## 业务流程

```
贴现申请 → 贴现申请应答 → 贴现完成
（持票人）   （金融机构/贴入人）
```

## 买断式贴现

- 持票人将票据权利完全转让给金融机构
- 金融机构取得票据到期兑付权利

## 回购式贴现

- 原贴现申请人、原贴入人按照协议约定，在**赎回开放期**赎回票据
- 具有融资性回购特征

## 贴现资金清算

贴现业务支持多种清算方式（FOP/DVP/PT+0/PT+1等），具体方式根据业务类型和时效要求配置。

## 关联

- 贴现是[[中国票据业务系统]]中票据流转的重要环节之一
- 贴现业务支持[[票据分包]]机制，可对票据包进行分包后贴现
- 贴现后票据可进入交易环节（转贴现、回购）或质押等后续操作
