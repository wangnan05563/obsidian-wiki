# 票据服务费计费缴费接口规范

**票据服务费计费缴费接口规范**是由[[上海票据交易所]]制定的直连接口规范分册，定义了票据业务系统中服务费计费与缴费环节的报文流程和 XML 报文格式。该规范涵盖计费信息通知、扣费结果通知及扣费状态查询三大业务场景。

## 业务场景报文流程

### 1. 票据服务费信息通知

每个计费周期结束后，[[上海票据交易所]]（票交所）计算各会员票据服务费用，基于计费信息向会员单位发送收费通知。会员收到通知后可了解当期账单明细。

### 2. 票据服务费扣费结果通知

票据服务费结算完成后，票交所通知会员业务扣费结果。若当期费用账单为 0，则不下发该通知。

### 3. 票据服务费扣费状态查询

参与者可向票交所发起单笔账单扣费结果查询申请，票交所将查询结果反馈至参与者。

## 报文（XML 格式）

规范定义了四类 XML 报文，均采用统一的扩展属性信息组件（`<ExtInfs>`）：

### CHS.001.002 — 票据服务费信息通知报文

- **功能**：票交所向会员发送计费周期服务费账单通知
- **核心要素**：服务费期数、计费起止日期、扣费日期、机构参与者代码、各项费用明细（交易手续费、结算过户费、账户维护费、其他结算费、终端使用费等）、计费总额、优惠金额、违约金、应缴金额
- **计算关系**：
  - 计费总额 = 交易手续费 + 结算过户费 + 账户维护费 + 其他结算费 + 其他费用
  - 应缴金额 = 计费总额 - 优惠金额 + 违约金
- **扩展属性**：支持 EXTFEE（其他费用）等扩展信息

### CHS.002.002 — 票据服务费扣收结果通知报文

- **功能**：结算完成后通知扣费结果
- **核心要素**：服务费期数、扣费日期、应缴金额、付款方机构参与者代码、大额支付系统报文标识号、扣费结果
- **扣费结果**：清算成功 / 清算失败
- **处理规则**：当期费用为 0 时不下发通知

### CHS.003.002 — 票据服务费扣费状态查询申请报文

- **功能**：参与者向票交所发起单笔账单扣费结果查询
- **核心要素**：机构参与者代码、服务费期数（需为已出账单）

### CHS.004.002 — 票据服务费扣费状态查询应答报文

- **功能**：票交所将查询结果反馈至参与者
- **核心要素**：原报文标识、处理结果码、服务费期数、机构参与者代码、应缴金额、扣费结果
- **扣费结果**：清算成功 / 清算失败 / 排队处理中 / 待处理

## 关键术语

| 术语 | 说明 |
|------|------|
| **服务费期数** | 账单计费周期时间，格式如 201901 |
| **计费总额** | 各项费用加总（不含优惠和违约金） |
| **优惠金额** | 满足优惠条件后计算的减免金额 |
| **违约金** | 对逾期缴纳账单计收的罚金 |
| **应缴金额** | 实际应缴纳金额 = 计费总额 - 优惠金额 + 违约金 |
| **机构参与者代码** | 银行/非银会员为法人代码；资管/存托会员为产品代码 |

## 扩展属性组件

报文统一使用扩展属性信息组件（`<ExtInfs>`），支持灵活的扩展字段。扩展属性包括属性名（`<Name>`，Max150Text）和属性值（`<Value>`，UnType）。V1.3 版本（2025-11-17）启用了 EXTFEE 扩展字段用于填写其他费用。
