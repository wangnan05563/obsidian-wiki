# 供应链票据

供应链票据是供应链金融创新的重要实践，是出票人在供应链场景下，基于真实交易关系，通过符合条件的供应链平台在[[上海票据交易所]]签发的[[电子商业汇票]]。

## 基本概念

供应链票据属于《票据法》等相关法律法规规范的正规金融工具，是出票人通过供应链平台在票交所签发的电子商业汇票。银票和财票以8开头，商票以7开头。

票据附加展示信息作为票据正面的补充信息，各供应链平台应在查询时向企业进行完整展示。

## 发展历程

- **2019年6月**：票交所发布《供应链票据平台接入规则（试行）》，明确了平台的接入标准和流程规则
- **2020年4月**：中国票据业务系统一期（供应链票据平台）投产上线
- **2020年9月**：人民银行等八部委出台《关于规范发展供应链金融 支持供应链产业链稳定循环和优化升级的意见》（银发〔2020〕226号）
- **2021年1月**：供应链票据平台试运行，相继上线企业信息登记、等分化签发和流转、票据贴现和交易、到期线上清算等功能
- **2021年8月**：发挥供应链票据支付和融资属性
- **2022年6月**：承载着票据全生命周期业务的中国票据业务系统全面上线，供应链票据平台为中国票据业务系统的重要组成部分
- **2022年9月**：金融机构可将持有的供应链票据向人民银行申请办理再贴现业务
- **2022年11月**：中国人民银行、中国银保监会发布《商业汇票承兑、贴现与再贴现管理办法》，明确供应链票据属于电子商业汇票
- **2023年9月**：国务院印发《关于推进普惠金融高质量发展的实施意见》，规范发展小微企业供应链票据等业务
- **2024年8月**：供应链票据业务功能优化升级，新增有限追索服务和资产证券化业务等相关功能点
- **2025年4月**：人民银行等六部委发布《关于规范供应链金融业务 引导供应链信息服务机构更好服务中小企业融资有关事宜的通知》（银发〔2025〕77号），推动供应链票据扩大应用

截至2025年9月，共有56家符合条件的供应链平台接入票交所。

## 业务实践

### 业务系统架构

企业（出票人）通过供应链平台在[[中国票据业务系统]]签发的电子商业汇票，即为供应链票据。架构包括：
- 核心企业、一级供应商、N级供应商、经销商等供应链企业
- 供应链平台（整合订单、存货、仓单、应收账款等信息）
- 供应链票据平台
- 金融机构

### 业务功能

- **签发环节**：出票、承兑、收票
- **流转环节**：背书转让、跨平台流转
- **融资环节**：线上贴现
- **交易环节**：转贴现、回购
- **再贴现环节**
- **到期处理**

可签发银票和商票，支持交易关系信息查询和上传。

### 业务特点

1. 利用供应链平台"四流合一"的特点，从源头上强化票据真实交易关系
2. 支持核心企业通过平台掌握全链路信息
3. 科技赋能，实现等分化签发，解决企业持票金额与付款金额不匹配的痛点
4. 通过供应链平台，借助核心企业信用资源，将金融资源向上下游延展推送，提高中小微企业融资能力

## 产品优势

| 优势 | 供应链票据 | 电子凭证 |
|------|-----------|----------|
| 账期固定 | 最长期限6个月，系统刚性控制 | 期限控制弱，事后监测为主 |
| 法律保障 | 遵从《票据法》，债权债务关系清晰 | 依据《民法典》，依靠协议约定 |
| 市场透明度 | 在票交所登记托管，全生命周期系统操作，信息披露 | 信息由企业或银行自建平台记录，无信息披露机制 |
| 融资成本 | 可转贴现流通，引入低成本同业资金和再贴现政策 | 主要通过商业或银行保理融资，成本较高 |
| 打破封闭循环 | 连接金融机构和供应链平台，支持跨平台、跨渠道流转 | 仅在平台内部流转 |

## 业务创新

### 有限追索服务

有限追索是票交所推出的一项追索机制创新，指从票据签发开始，由市场参与者秉承"自愿参与、自主选择、自负其责"原则，就追索权范围通过协议约定达成一致，同意持票人不可撤销地放弃对承兑人及其保证人（如有）以外各前手的追索权。

**业务要点**：
1. 通过法治化方式约定追索权范围，市场参与者均应签署承诺书
2. 通过市场化方式自主选择是否参与，不影响其他追索权范围完整的票据
3. 覆盖票据全生命周期，各环节均可接受有限追索服务
4. 接受有限追索服务的市场参与者均应履行承诺
5. 相关规则与现有票据业务规则保持一致

**经济社会效益**：
1. 有利于满足企业财务管理需求，推动企业账款清欠化解，实现会计出表
2. 有利于促进持票人权利的合理平衡和保护
3. 有利于促进金融机构更好服务实体经济，释放风险资本
