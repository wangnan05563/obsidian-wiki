# 恒生票据5.0 异常码规范

## 概述

异常码规范定义了恒生票据5.0平台中异常码的定义标准和使用原则，以保证异常信息的统一性和可追溯性。

## 异常码定义规范

- 异常码应具有明确的层级结构
- 通过异常码能够快速定位问题所在模块和错误类型
- 异常码格式统一、便于记忆

## 异常码使用原则

1. 异常码必须唯一
2. 异常码需附带清晰的中文错误描述
3. 不同场景使用不同的异常码，禁止复用
4. 异常码应区分系统异常和业务异常

## 异常码错误示例

规范中列举了错误的使用方式和正确的使用方式对比，帮助开发者避免常见问题。

## 关于错误码适配

- 错误码需要兼容不同版本的接口
- 对外的错误码应进行适配转换
- 内部错误码不应直接暴露给前端

## 常用词汇规范

定义了一组统一的异常描述常用词汇，确保团队使用一致的术语表达。
