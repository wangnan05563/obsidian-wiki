# 恒生电子

**恒生电子股份有限公司**（Hundsun Technologies Inc.）是中国领先的金融科技上市公司，为证券、基金、银行、保险、信托等金融机构提供全面的 IT 解决方案。

## 票据产品

恒生电子在票据领域拥有多款核心产品：

- [[电子商业汇票综合处理平台]]（BBSP）— 为商业银行开发的票据业务管理总线系统
- [[hundsun-bill-trading-platform-v5]] — 票据交易管理平台 V5.0 后端开发平台
- [[hundsun-bill-trade-v5-frontend]] — 票据交易管理平台 V5.0 前端开发指导

## 编码规范

恒生电子制定了完善的企业级编码规范体系，涵盖 Java、前端（HTML/CSS/JS/Vue）等各类技术栈。
