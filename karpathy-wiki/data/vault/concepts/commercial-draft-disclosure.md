# 商业汇票信息披露制度

## 概述

商业汇票信息披露制度是中国票据市场信用体系建设的核心制度安排，由中国人民银行主导建立，旨在通过强制性的信息披露机制，增强票据市场透明度，防范票据信用风险。该制度的核心法规依据是《商业汇票承兑、贴现与再贴现管理办法》（2022年修订）和中国人民银行〔2020〕第19号公告。

## 制度背景

### 商业汇票的特点与问题

商业汇票具有**凭证法定、账期固定、市场接受度和流通性较高**等优势，但实践中存在以下问题：
- 商业承兑汇票流通性、融资便利性较低
- 商业信用体系不健全
- 市场信用分层严重

### 信息披露的益处

1. 增强票据流通性
2. 提高融资便利性
3. 降低融资成本
4. 防范票据市场风险

### 制度建设历程

| 时间 | 事件 |
|------|------|
| 2020年1月 | 票交所上线试运行票据信息披露平台，首批试点企业21家 |
| 2020年6月 | 人民银行发布《关于规范商业承兑汇票信息披露的公告（征求意见稿）》 |
| 2020年9月 | 人民银行等八部门联合发布供应链金融意见，提出加快实施信息披露制度 |
| 2020年12月 | 人民银行发布2020年第19号公告 |
| 2021年8月 | 票交所出台《商业承兑汇票信息披露操作细则》 |
| 2022年11月 | 人民银行、银保监会联合修订发布《商业汇票承兑、贴现与再贴现管理办法》 |

### 核心法规文件

- **《商业汇票承兑、贴现与再贴现管理办法》**（2022年11月发布，2023年1月1日施行）
- **中国人民银行〔2020〕第19号公告**
- **《商业汇票信息披露操作细则》**（由[[票据信息披露平台|上海票据交易所]]制定）

## 信息披露主体

信息披露的主体是**商业汇票的承兑人**，根据票据类型分为：

| 票据类型 | 承兑人类型 |
|----------|------------|
| 商业承兑汇票 | 企业 |
| 财务公司承兑汇票 | 财务公司 |
| 银行承兑汇票 | 银行 |

## 披露内容

### 商业汇票主要要素（承兑信息）

商业承兑汇票和财务公司承兑汇票的承兑人应披露每张已收票票据的主要要素，至少包括：
- 出票日期
- 承兑日期
- 票据号码
- 出票人名称
- 承兑人名称
- 承兑人统一社会信用代码
- 票面金额
- 票据到期日

### 承兑人信用信息

承兑人出现以下情况之一时，应当披露信用信息：
1. 当月有承兑业务发生
2. 当月有票据逾期行为发生
3. 月末有承兑余额

信用信息包括：
- **累计承兑发生额**：当年1月1日以来累计承兑的票据金额
- **承兑余额**：已承兑但未结清的票据金额
- **累计逾期发生额**：近5年内发生过逾期的票据金额
- **逾期余额**：发生逾期且未结清的票据金额

### 各类票据披露要求对照

| 票据类别 | 商业汇票主要要素（承兑信息） | 承兑人信用信息 |
|----------|:--------------------------:|:------------:|
| 商业承兑汇票 | ✓ | ✓ |
| 财务公司承兑汇票 | ✓ | ✓ |
| 银行承兑汇票 | | ✓ |

## 披露平台与方式

### 披露平台

[[票据信息披露平台]]（https://disclosure.shcpe.com.cn）是中国人民银行认可且唯一指定的官方披露平台，由上海票据交易所建设运营。

### 注册方式

- **企业**：自主登录票据信息披露平台线上注册
- **金融机构**：填写《金融机构票据信息披露平台信息登记表》，用印后通过中国票据交易系统预留邮箱发送至信息披露工作邮箱，由票交所代为注册

### 披露时间要求

- **商业汇票主要要素**：承兑完成后及时披露（收款人已签收的票据）
- **承兑人信用信息**：每月前10日内完整披露截至上月末的信息

### 信息查询

金融机构、持票企业或其他社会公众可通过**票据号码、承兑人名称或统一社会信用代码**查询披露信息。查询信息仅作为业务参考。

## 风险控制

### 未披露主要要素的影响

1. **贴现、质押、保证业务受限**：金融机构发现未披露或信息不符的，不得办理相关业务
2. **承兑业务受限**：持票人提醒披露后，承兑人须在3个工作日内披露；否则票交所暂停其承兑服务

### 延迟披露的影响

承兑人连续3个月以上未披露信用信息的，构成**延迟披露**，最近2年内发生延迟披露的：
- 承兑人：票交所暂停承兑服务
- 贴现人：票交所暂停贴现服务
- 企业：金融机构不得为其办理承兑业务
- 已承兑票据：金融机构不得办理贴现、质押、保证

### 延迟披露的补披露流程

1. 学习信息披露相关制度
2. 绑定所有电票业务账户
3. 设置自动披露
4. 向票交所（ids@shcpe.com.cn）发邮件申请解除业务限制
5. 预审通过后将申请材料原件用印后寄送至票交所

### 票据逾期判定

承兑人到期后拒绝付款或未按规定及时结清的，构成**票据逾期**。

| 票据类型 | 逾期判定标准 |
|----------|------------|
| 银票/财票（ECDS未贴现） | 提示付款次一个工作日未结清 |
| 商票（ECDS未贴现） | 提示付款次日起3日内未结清 |
| 已贴现电票 | 提示付款当日未结清 |

### 逾期层级体系

- **票据逾期**：到期后拒绝付款或未及时结清
- **承兑人逾期**：6个月内发生3次及以上票据逾期，且月末有逾期余额或当月有逾期行为
- **持续逾期**：6个月内发生3次及以上承兑人逾期，且当月构成承兑人逾期

### 逾期异议申请

因以下原因导致逾期的，可向票交所申请异议：
- 地方特殊节假日与法定节假日不一致
- 疫情防控导致经营场所被封控
- 刑事/民事纠纷有权拒绝付款
- 有权机关冻结止付
- 资金账户司法冻结
- 开户机构系统问题
- 自然灾害等不可抗力

申请流程：发送电子扫描件至 ids@shcpe.com.cn 预审，通过后寄送原件至上海票据交易所监测部。

## 2022年《管理办法》主要修订内容

1. **明确票据性质与分类**：商业汇票包括纸质或电子形式的银行承兑汇票、财务公司承兑汇票、商业承兑汇票等；明确供应链票据属于电子商业汇票
2. **强调真实交易关系**：银票出票人、贴现申请人与前手之间的真实交易关系和债权债务关系
3. **强化信息披露及信用约束**：发生持续逾期或未按规定披露信息的承兑人两年内不得开展相关业务
4. **加强风险控制**：设置最高承兑余额和保证金余额比例上限；将最长期限由1年调整至6个月
