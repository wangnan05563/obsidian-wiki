# 纸票业务直连接口规范

**纸票业务直连接口规范**是 [[上海票据交易所]] 发布的《中国票据业务系统直连接口规范》的纸票业务分册，定义了纸质商业汇票（纸票）在中国票据业务系统中的信息登记、流转、查询等业务的报文标准。

## 基本信息

- **发布机构**：[[上海票据交易所]]
- **最新版本**：V1.4（2026年6月）
- **适用范围**：纸质商业汇票（银行承兑汇票/商业承兑汇票）
- **通信方式**：XML格式报文直连接口
- **所属系统**：[[中国票据业务系统]]

## 报文结构规范

每类报文均包含以下通用结构：

```
<MsgId>        — 报文标识（标识号+时间戳）
<RgtInf>       — 登记信息（机构代码+日期）
<CdInfs>       — 票据信息集合（可批量）
  <CdInf>      — 单笔票据信息
    <CdType/>  — 票据种类
    <CdNo/>    — 票据号码
    <CdAmt/>   — 票据金额
    <IssDt/>   — 出票日期
    <DueDt/>   — 到期日
    ...
<ExtInfs>      — 扩展信息（可选）
```

## 关键业务规则

1. **批量登记**：同一报文可包含多张票据，max值见基础数据文件
2. **全有或全无**：批量登记中任一票据校验失败，全部登记失败
3. **票据号码唯一性**：已登记的票据号码不得重复登记
4. **作废票据**：已作废或未用退回的票据不得重新登记
5. **错误反馈**：通过通用确认报文反馈第一张错误票据的原因

## 付款确认场景

付款确认支持多种复杂场景：
- **场景一**：单次影像/实物确认（一个来回）
- **场景二**：补录影像或实物确认（两个来回）
- **场景三**：影像确认被拒绝后穿插保证增信流程
- **场景四**：影像付款确认发起后、未应答前穿插保证增信流程
