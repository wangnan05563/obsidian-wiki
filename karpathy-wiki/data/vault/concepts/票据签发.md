# 票据签发

票据签发是[[中国票据业务系统]]中的票据生命周期起点，包含**出票信息登记**、**提示承兑**及**提示收票**三个业务子流程，并支持**撤票**操作。

## 业务流程

```
出票信息登记 → 提示承兑申请 → 提示承兑应答 → 提示收票申请 → 提示收票应答 → 票据签发成功
```

**角色**：
- **出票人**：基于支付需要，进行票据信息出票登记
- **承兑人**：对提示承兑申请作出应答
- **收款人**（收票人）：对提示收票申请作出应答

## 业务子流程

### 1. 出票信息登记
出票人基于支付需要，进行票据信息出票登记的行为。出票日期 = 出票登记成功当日。

### 2. 提示承兑
出票人出示票据，并要求付款人承诺付款的行为。

### 3. 提示收票
出票人向收款人交付电票，发起提示收票申请，由收款人作出应答。

### 4. 撤票
出票人在电票出票信息登记成功后、收款人对提示收票申请应答同意前，可以对电票作**未用退回**处理。

## 承兑限额监管

依据《商业汇票承兑、贴现与再贴现管理办法》：

- **第二十四条**：银行承兑汇票和财务公司承兑汇票的**最高承兑余额不得超过该承兑人总资产的15%**。保证金余额不得超过该承兑人吸收存款规模的10%。人民银行和银保监会可以根据金融机构内控情况设置承兑余额与贷款余额比例上限等其他监管指标。
- **第三十五条**：超过承兑限额、付款期限规定的，由人民银行及其分支机构、银保监会及其派出机构对承兑人进行警告、通报批评，并由银保监会及其派出机构依法处以罚款。

## 涉及的票据发行角色

票据签发过程中涉及的角色包括：
- **出票人**
- **承兑人**
- **收票人**

## 票交所处理流程

### 出票登记
1. 出票人发起出票登记
2. 参与者服务机构转发申请
3. 票交所返回票据包号等

### 提示承兑/提示收票
1. 出票人发起申请
2. 参与者服务机构转发申请
3. 票交所校验并转发申请
4. 接收方应答
5. 票交所转发应答结果
