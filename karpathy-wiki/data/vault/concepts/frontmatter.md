# Frontmatter

**Frontmatter** 是 Markdown 文件开头的 YAML 元数据块，用于定义页面的标题、类型、创建时间、更新时间、来源和标签等结构化信息。

## 规范字段

| 字段 | 说明 |
|------|------|
| title | 页面标题 |
| type | 页面类型（entity/concept/comparison/query） |
| created | 创建日期 |
| updated | 更新日期 |
| source | 原始资料来源 |
| tags | 标签列表 |
