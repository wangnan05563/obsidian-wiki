# 恒生票据5.0 Java编码规范

## 概述

**恒生票据5.0 Java编码规范** 是采用票据5.0平台的项目必须遵循的开发规范，最终作为项目评审与验收依据。该规范以《恒生Java编码规范.pdf》为基准，在此基础上进行票据系统的扩展与补充。

## 规范原则

1. **遵循业界标准** — 以行业通用最佳实践为基础
2. **可读性强，意义清楚** — 代码应当易于理解
3. **整洁严谨、风格统一** — 保持代码的一致性和高质量

## 使用范围

适用于采用 **票据5.0平台** 的所有项目，并作为项目评审与验收依据。

## 核心要点

### 命名规约

- **Service/ATOM/DAO层方法命名**：
  - `get` 前缀 — 获取单个对象
  - `query`/`find` 前缀 — 获取多个对象
  - `count` 前缀 — 获取统计值
  - `save`/`insert`/`add` 前缀 — 插入方法（推荐 `save`）
  - `remove`/`delete` 前缀 — 删除方法（推荐 `remove`）
  - `update` 前缀 — 修改方法
- 包名统一小写，类名采用驼峰原则（首字母大写）
- 个性化服务命名时基于产品化服务增加前缀 `xxBank`
