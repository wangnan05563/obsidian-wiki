# Test Document Series

The **Test Document Series** is a collection of numbered test documents (including [[Test Document 17]]) created for batch compilation testing. Each document contains standardized minimal content to validate the compilation pipeline's ability to parse markdown, extract metadata, and generate structured wiki pages.

## Purpose

- Validate frontmatter parsing across multiple documents
- Test entity extraction on short-form content
- Ensure batch processing produces consistent output
- Verify [[wiki-batch-compile]] workflow integrity
