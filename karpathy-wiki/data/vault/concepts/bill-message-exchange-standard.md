# 票据报文交换标准

票据报文交换标准是 [[上海票据交易所]] 定义的、用于 [[中国票据业务系统直连接口规范|中国票据业务系统]] 各节点间交换业务数据的通信规范。

## 报文结构

报文由**报文头**和**报文体**组成：

```
<Document>          ← 根报文域
  <Header>          ← 报文头
    ...
  </Header>
  <Body>            ← 报文体
    <报文块1>       ← 由多个报文域组成
      <报文域1>     ← 封装业务要素
      </报文域1>
    </报文块1>
  </Body>
</Document>
```

## 报文头格式

报文头包含消息的路由和控制信息，包括：
- 报文标识号
- 发送方/接收方代码
- 报文类型
- 时间戳
- 加密标识

## 报文编号

每个报文有唯一的报文编号，用于标识和追踪。

## 报文加密

规范支持报文加密传输，安全控制分册提供详细说明。

## 报文清单

规范定义了多类业务报文，包括：

### 业务主体类
- 参与者信息登记报文
- 企业参与者补充信息登记确认报文

### 票据产品类
- 票据查询报文（PAY.014.001）
- 票据查询应答报文（PAY.015.001）
- 线上票据支付确认报文（PAY.016.001）
- 主动付款申请报文（NES.016.001）
- 支付订单推送报文（PAY.017.001）
- 支付信息通知报文（PAY.018.001）
- 贴现业务办理要求通知报文（CPP.034.001）
- 信托转入/转出报文
- 意向询价撤销报文

### 迁移票据类
- 迁移票据业务申请/撤销/转发/应答/通知报文

### 查询类
- 参与者票据清单查询申请/应答报文（CIM.034.001 / CIM.035.001）

## 票据状态体系

票据状态分为多维度：

- **票据状态**：票据当前所处的生命周期状态
- **票据流通标志**：TF0302 由"已锁定"改为"处理中"
- **票据库存状态**：票据在系统中的库存状态
- **票据风险状态**：票据的风险标识
- **票据支付状态**：PS10 表示"已发起"
- **交易业务单状态**：包含贴现对话报价单状态等

## 数据类型

规范定义了丰富的数据类型枚举，涵盖：
- 发票类型（InvTp）：含全电发票等
- 交易方式（TraMod）
- 支付方式（PymnMthdCode）
- 业务类别（BusiCategory）
- 清退原因（ClrRsn）
- 产业属性标签等
