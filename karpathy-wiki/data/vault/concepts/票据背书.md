# 票据背书

## 概述

票据背书是指**持票人将票据权利依法转让给他人**的票据行为。本节所指转让背书为**企业间转让背书**，持票人（即背书人）操作背书转出，收票人（即被背书人）作出同意应答，完成票据权利交割。

## 业务流程

```
背书转让申请 → 背书转让应答 → 背书成功
（背书人）      （被背书人）
```

### 完整交互流程

1. 背书人（申请人）发起背书申请
2. 参与者服务机构转发申请
3. 票交所校验并转发申请
4. 被背书人（接收人）应答
5. 参与者服务机构转发应答结果
6. 票交所返回应答结果

## 背书与票据分包

背书时可支持票据分包流转。例如：
- 持票人A持有票据包（子票区间 1-2000000，金额 20000）
- 向企业B发起转让背书，背书金额 10000
- 分包为：子票区间 1-1000000（金额 10000）和 1000001-2000000（金额 10000）
- 背书金额对应的子区间转让给B

## 票付通业务

在支付端推广**票付通**业务，支持票据即时支付、见证支付及票据+现金组合支付。

### 票付通流程

1. 买卖双方在B2B平台达成贸易订单
2. 收银台跳转，将订单信息传递至付款人开户行网银
3. 票据签发+锁票（挑票+背书+锁票），买方不可随意撤销票据，卖方不可签收
4. 卖方发货
5. 确认收货
6. 卖方签收票据（可自动签收）

## 关联

- 背书支持[[票据分包]]机制，分包可在背书时自动触发
- 背书是[[中国票据业务系统]]中票据流转的重要环节之一
