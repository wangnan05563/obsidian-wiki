# 票据业务总体规则

## 概述

[[中国票据业务系统]] 在主要业务流程之下制定了多项总体规则，涵盖资金清算、权限控制、连续性校验、信息校验和时序节假日等方面。

## 资金清算

各类业务支持的资金清算方式和时效：

| 业务种类 | FOP/DVP | 逐笔/批量 | T+0 / T+1 |
|---------|---------|----------|----------|
| 贴现 | ✓ | 逐笔/批量 | T+0/T+1 |
| 交易 | ✓ | 逐笔/批量 | T+0/T+1 |
| 再贴现 | ✓ | 逐笔/批量 | — |
| 提示付款 | ✓ | 逐笔 | T+0/T+1 |
| 线上追偿 | — | 逐笔 | T+0/T+1 |
| 贴现前追索清偿 | ✓ | 逐笔/批量 | T+0/T+1 |

## 权限控制 — 票据账户主动管理

### 机制
由客户委托一个具有电票功能的结算账户的开户机构（开户银行或所属集团财务公司）在票交所系统登记该客户所有可办理电票业务的结算账户信息。

### 功能
- 企业在多个金融机构办理电票业务的，可通过指定的一个金融机构对其在各机构账户的业务权限进行关闭、删减等操作
- 实现企业对账户的**自主管理**、**穿透控制**
- 有效防范企业被不法分子**假冒身份开立虚假账户**并办理票据业务的风险

## 连续性及一致性校验

### 一致性校验
1. 业务申请或应答发起时，使用的发起方（企业）信息、接收方（企业）信息，跟系统当前最新的备案信息一致

### 连续性校验
1. 当前业务申请的发起方，应为**前手业务的接收方**
2. 当前业务应答的发起方，应为**相应业务申请的接收方**

## 信息披露及相关校验

参见 [[票据信息披露机制]] 页面。

## 时序和节假日

### 日内时序
- **非交易类业务**：08:00-20:00（21:00 营业日终）
- **交易类业务**：营业日内

### 营业日与节假日
- **非交易类业务**：一般不区分节假日
  - **例外**：提示付款
- **交易类业务**：仅在营业日办理
