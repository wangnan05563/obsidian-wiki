# 中国票据业务系统直连接口规范

《中国票据业务系统直连接口规范》是由 [[上海票据交易所]] 制定并发布的接口技术规范，用于规范票据业务系统各参与方之间的报文交换标准。最新版本为 V1.4（2026年6月）。

## 文档结构

规范分为多个分册，本资料为**概述分册**，内容包括：

1. **报文交换标准概述** — 术语说明、业务标准
2. **报文格式概述** — 报文结构、报文头格式、报文体格式、报文编号、报文加密
3. **报文数据定义** — 数据类型、票据状态、流通标志、库存状态、风险状态、支付状态
4. **公共组件** — 参与者信息、业务信息、签章、票据信息、结算信息等14个组件
5. **附录** — 报文清单、基础数据清单、业务编号、状态流转表等13个附录

## 报文交换标准

### 术语

- **业务要素**：业务数据项的抽象名称，业务的基本组成单位
- **报文**：系统节点间交换业务数据的基本单位，由报文头和报文体组成
- **报文块**：报文的基本组成单位，使用XML标签界定
- **报文域**：报文块的基本组成单位，每个报文域封装一个或多个业务要素
- **根报文域**：报文XML文档的根节点，标签固定为 `<Document/>`

### 字符集和编码

- 采用 Unicode 字符集，UTF-8 编码方式
- 对于禁止中文的 Text 类型字段，只允许 X 字符集（英文、数字及特定特殊字符）
- 特殊字符 `<`、`>`、`&`、`'`、`"` 需进行转义处理

## 报文分册

该规范按业务领域分为多个分册：

- **业务主体分册**：参与者信息登记等
- **票据产品分册**：票据查询、支付、贴现等
- **迁移票据业务分册**：存量票据迁移
- **安全控制分册**：加密与安全
- **银行账户分册**：账户管理
