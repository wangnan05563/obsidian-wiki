# Bidirectional Linking

**Bidirectional Linking** is a convention in the knowledge base that ensures related pages reference each other. This creates a cohesive network of information and improves navigation and context retrieval.

## Principles

- Every meaningful connection should be reciprocal where possible.
- Links should point to specific, relevant topics.
- Maintain consistency in linking style and formatting.

## Examples

- [[wiki-compile]] references [[Test Document 14]] as a test case.
- [[Test Document 14]] links back to [[wiki-compile]].
