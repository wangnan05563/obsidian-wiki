# 中国票据业务系统直连接口规范（ECDS迁移票据业务分册）

## 概述

**中国票据业务系统直连接口规范——ECDS迁移票据业务分册** 由[[上海票据交易所]]发布（2026年6月，V1.4），旨在推进**电子商业汇票系统（ECDS）** 数据迁移工作的实施。该规范对迁移中各业务场景的报文流程、报文数据定义、报文格式规范等规则予以明确。

该分册是 [[中国票据业务系统直连接口规范]] 系列的重要组成部分，与[[ECDS融合]]项目的第三阶段（ECDS存量数据迁移）密切相关。参见 [[票据业务系统非交易业务客户端功能]] 了解客户端模式下ECDS迁移票据的业务办理流程。

## 适用范围

本分册适用于 **ECDS 存量未结清票据在数据迁移后的到期后业务办理**。

## 核心术语

| 术语 | 定义 |
|------|------|
| **迁移票据** | ECDS中所有到期未结清、未作废、未失效的，在迁移时点一次性全部迁移至票据业务系统迁移模块中的票据 |
| **直连模式** | 会员机构开通了MCP.001~MCP.005共5个直连报文权限的业务处理模式 |
| **客户端模式** | 会员机构仅开通迁移票据业务通知报文（MCP.005.001）直连报文权限的业务处理模式 |

## 业务场景与报文流程

### 1. 逾期提示付款
持票人在票据到期后未及时提示付款，可在迁移后办理逾期提示付款业务。

### 2. 追索
#### 2.1 追索通知
- 在被追索人发起追索同意清偿申请前，追索人可继续向其他被追索人发起追索通知

#### 2.2 追索同意清偿
- 被追索人1发起追索同意清偿申请后，其余被追索人不可发起
- 若追索人拒绝被追索人1的申请，则其余被追索人可以继续发起

#### 2.3 追索通知清分失败
清分失败时触发相应通知流程。

### 3. 业务撤销
允许对已发起的迁移票据业务进行撤销操作。

### 4. 通用通知
- 会员采取客户端模式时，业务发生时通过该报文通知其业务变化
- 票交所触发持票人变更或撤销时通过该报文通知
- 持票人可通过客户端自行申请下发业务通知

## 迁移业务报文清单

| 报文编号 | 报文名称 | 报文方向 | 是否新增 | 是否加签 | 是否加密 | 是否对账 |
|----------|----------|----------|----------|----------|----------|----------|
| MCP.001.001 | 迁移票据业务申请报文 | 参与者→票交所 | 是 | 是 | 是 | 是 |
| MCP.002.001 | 迁移票据业务撤销报文 | 参与者↔票交所 | 是 | 是 | 是 | 是 |
| MCP.003.001 | 迁移票据业务转发报文 | 参与者←票交所 | 是 | 是 | 是 | 是 |
| MCP.004.001 | 迁移票据业务应答报文 | 参与者↔票交所 | 是 | 是 | 是 | 是 |
| MCP.005.001 | 迁移票据业务通知报文 | 参与者←票交所 | 是 | 是 | 是 | 是 |
| CIM.001.002 | 通用业务确认报文 | 参与者←票交所 | 否 | 否 | 否 | 否 |

> 适用的会员类型：B.银行、F.财务公司、I.其他、R.供应链平台、E.直连B2B平台

## 数据类型定义

规范中定义了以下数据类型（仅限本分册范围内使用）：

| 类型名称 | 说明 |
|----------|------|
| MaxxxxText | 字符串，最少1字符，最多xxx字符 |
| MaxxxxNumericText | 数字串，最少1位，最多xxx位 |
| ISODateTime | 格式 `yyyy-mm-ddTHH:MM:SS` |
| ISODate | 格式 `yyyy-mm-dd` |
| PercentageRate | 7位数字，小数部分6位，表示百分比 |
| CurrencyAndAmount | 金额，总长19位（含小数点），币种固定为CNY |
| BanEndorsementMarkCode | 可再转让/不得转让标记 |
| SignUpMarkCode | 同意/拒绝/清分失败应答标记 |
| DraftTypeCode | 银票/财票（AC01）或商票（AC02） |
| RoleCode | 参与方角色编码 |
| RecourseTypeCode | 拒付追索/非拒付追索 |
| EcdsDishonorCode | 拒付理由编码（DC00~DC09） |
| MCPBusiCategory | 迁移业务类别（逾期提示付款/追索通知/追索同意清偿） |
| MCPBusiScenariosCode | 迁移业务场景编码（MP0501~MP0516等） |

## 报文组件

规范定义了以下报文组件（XML格式）：

1. **迁移票据参与者信息组件** — 参与方身份信息
2. **迁移票据业务信息组件** — 业务申请详细信息
3. **迁移票据业务应答组件** — 应答结果信息
4. **迁移票据状态信息组件** — 票据当前状态
5. **迁移票据通知信息组件** — 通知内容
6. **迁移票据基本信息组件** — 票据基础要素
7. **迁移票据历史详细信息组件** — 历史行为信息（含贴现、质押解除、提示付款等）

## XML报文格式

五种核心报文均为XML格式：

| 报文 | 功能 | 文件编号 |
|------|------|----------|
| MCP.001.001 | 迁移票据业务申请 | 3.1 |
| MCP.002.001 | 迁移票据业务撤销 | 3.2 |
| MCP.003.001 | 迁移票据业务转发 | 3.3 |
| MCP.004.001 | 迁移票据业务应答 | 3.4 |
| MCP.005.001 | 迁移票据业务通知 | 3.5 |
