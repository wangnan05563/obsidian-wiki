# 知识库目录

- [[llm-wiki]] — 基于大语言模型的 AI 自动编译知识库系统，由 Karpathy 提出
- [[harness]] — LLM Agent 运行时，提供工具调用循环、状态管理、重试、预算控制
- [[vault]] — LLM Wiki 的 Markdown 存储层，按 entity/concept/comparison/query 分类组织页面
- [[wiki-comparison]] — 传统 Wiki 与 LLM Wiki 在多维度上的对比分析
- [[rag]] — RAG（Retrieval-Augmented Generation，检索增强生成）——结合检索与生成的技术范式，通过索引、检索、增强、生成四步流程增强 LLM 回答的准确性和时效性。
- [[llm]] — 大语言模型（LLM）——基于 Transformer 架构的预训练语言模型，在 RAG 系统中作为生成引擎。
- [[embedding]] — 嵌入（Embedding）——将非结构化数据映射为稠密向量的技术，用于 RAG 系统中的相似度检索。
- [[vector-database]] — 向量数据库——专门存储和检索向量嵌入的数据库，RAG 系统的核心基础设施。
- [[Mixture of Experts]] — 一种稀疏激活的神经网络架构，通过路由器动态分配输入给专家子模型，在提升容量的同时控制推理成本。
- [[稠密模型]] — 传统神经网络架构，推理时激活全部参数，计算成本与参数量严格正相关。
