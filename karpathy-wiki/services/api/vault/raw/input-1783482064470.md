# LLM Wiki 简介

LLM Wiki 是一个基于大语言模型的知识库系统。它由 Karpathy 提出，核心理念是"用 LLM 编译知识"。

## 核心组件

### Harness
Harness 是 LLM Agent 运行时，包裹 LLM 提供工具调用循环、状态管理、重试、预算控制。公式：Agent = LLM + Harness。

### Vault
Vault 是知识库的存储层，使用 Markdown 文件存储页面。页面分为四类：entity（实体）、concept（概念）、comparison（对比）、query（问答）。

### 双向链接
页面间通过 [[页面名]] 语法互相引用，形成知识图谱。例如 [[harness]] 和 [[vault]] 是两个关键概念。

## 与传统 Wiki 的区别

传统 Wiki 需要人工编写页面，LLM Wiki 通过 AI 自动从原始资料编译生成结构化页面，大幅降低维护成本。
